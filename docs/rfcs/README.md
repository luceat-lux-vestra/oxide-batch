# Request for Comments

RFCs are used for significant product, compatibility, public API, persistence,
security, and governance changes.

## Index

No RFC has been accepted yet.

## Naming

Use `NNNN-short-title.md`. Allocate the next number when the RFC pull request is
opened. Copy [0000-template.md](0000-template.md).

RFC states are Draft, Proposed, Accepted, Rejected, Withdrawn, Implemented, and
Superseded. Acceptance records the decision; it does not imply implementation.
