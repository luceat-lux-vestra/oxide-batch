## Naming and states

Use `NNNN-short-title.md` and copy [the template](0000-template.md). Allocate
the next number when the RFC pull request is opened.

RFC states are Draft, Proposed, Accepted, Rejected, Withdrawn, Implemented, and
Superseded. Acceptance records a decision; it does not imply implementation.
An accepted RFC that changes architecture is followed by an ADR as required by
the [development process](../project/development-process.md).
