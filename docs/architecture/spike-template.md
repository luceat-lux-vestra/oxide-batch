# Architecture Spike: Question

- **State:** Planned
- **Owner:** GitHub handle
- **Issue:** link
- **Time/effort bound:** value
- **Decision/ADR:** link

## Decision to unblock

State the exact decision that cannot be made safely without evidence.

## Hypotheses

List falsifiable expectations for each credible option.

## Constraints

Record MSRV, toolchain, platform, dependency versions/features, database
version/configuration, correctness invariants, and excluded scope.

## Experiment

Provide commands, source location, fixtures, workload, injected failures, and
observations to collect. Another contributor must be able to reproduce it.

## Acceptance and rejection criteria

State the evidence that selects or rejects each option before running the
experiment.

## Results

Include raw outputs or artifact links, not only a conclusion. Record unexpected
behavior and measurement variance.

## Correctness and risk review

Cover transactions, restart, concurrency, cancellation, panic, sensitive data,
public API leakage, MSRV, and operations as applicable.

## Conclusion

State selected option, limitations, confidence, and unresolved questions.

## Follow-up

- ADR/RFC updates;
- implementation and test issues;
- risks added/closed;
- disposable code to retain or remove;
- evidence expiration/revisit trigger.
