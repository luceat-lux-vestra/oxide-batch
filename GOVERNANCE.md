# Governance

OxideBatch is currently maintained by `@luceat-lux-vestra`.

## Decision making

- Routine changes are decided through pull request review.
- Significant design changes require an RFC or architecture decision record.
- Compatibility, persistence schema, transaction semantics, public API, and
  security policy changes are always considered significant.
- Decisions and their rationale must be recorded in the repository.

## Maintainer responsibilities

Maintainers are responsible for:

- Reviewing changes for correctness, compatibility, and operational risk
- Protecting release credentials and repository settings
- Triaging security reports
- Enforcing the Code of Conduct
- Maintaining a transparent release and deprecation policy

## Evolution

Before adding another maintainer, this document will define nomination,
approval, removal, inactivity, and conflict-of-interest procedures. Repository
ownership may later move to a dedicated GitHub organization without changing
the project's license or public history.
