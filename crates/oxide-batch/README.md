# oxide-batch

The public facade crate for [OxideBatch](https://github.com/luceat-lux-vestra/oxide-batch),
an enterprise-ready batch processing framework for Rust inspired by Spring Batch.

> This crate is in its foundation phase. It does not yet expose a
> production-ready batch runtime API.

The facade crate will provide the supported public entry point and re-export
stable APIs from focused workspace crates as they are introduced.
